# Transcripts of your own videos

Put corrected transcripts of your own videos here, one file per video (`.md` or `.txt`).
Every agent reads them as examples of how you actually talk.

1. Transcribe the audio (e.g. ElevenLabs Scribe on the website; compare with Google Chirp 3 on 3 clips first).
2. Fix the transcript by hand so it matches exactly what you said, in Baghdadi.
3. Save it here, e.g. `2026-11-05-marketing-tip.md`.
4. Any Iraqi word you corrected that isn't in the word sheet: `content-workshop words add "<Iraqi>" "<Arabic>"`.

Up to ~12,000 characters of examples are sent with each request, so the best 10-20 clips are enough.
